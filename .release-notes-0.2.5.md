Proper per-day schedule control.

### Added
- **Per-day schedule switches** — one switch per day (Monday–Sunday) for each of the four schedule slots, so you can run a schedule on any combination of days (e.g. Mon/Wed/Fri). They're grouped under the device's **Configuration** section to keep the main view tidy. A schedule must always keep at least one day selected — turning off the last remaining day is refused, matching the Wallbox app.

### Changed
- `wallbox_ble.set_schedule`: the `days` field is now **required** (it no longer silently defaults to every day) and accepts friendly formats — a day-name list `[mon, wed, fri]`, a keyword (`all`, `weekdays`, `weekends`), a comma-separated string, or a Monday-first bitmask integer. A schedule with zero days is rejected.
- Setting a schedule **start** time on an empty slot now defaults the **stop** to start + 1 minute instead of a fixed 23:41. A newly created slot still defaults to all days — refine it with the per-day switches.

### Removed
- The single-select "Schedule Days" entity introduced in 0.2.4, replaced by the per-day switches.
